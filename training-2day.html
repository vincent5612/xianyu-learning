Day 1 · 培训完即发布

🔥 目标：培训结束后，每个学员发布2-3个产品

一、平台红线（10分钟）

🚫 五大绝对红线
红线后果
站外导流：引导微信/QQ/淘宝等外部平台交易封号
留联系方式：标题/描述/图片/私聊留任何联系方式限流/下架
极限词："全新""100%正品""全网最低"限流/下架
恶意改价：频繁/大幅调价（7天内超10%）降权
高危售后：拖延发货/无理拒退/态度恶劣降权/封号
⚠️ 其他违规
· 重复铺货（同一商品多个链接霸屏）
· 禁售商品（高仿/假货/盗版/管制刀具/易燃易爆）
· 同WiFi下多号操作 → 连坐封号
📌 散场前必须记住的3条
① 不要在闲鱼提微信
② 标题不要写"全新"
③ 7天内别大幅改价

二、上架三件套（25分钟）

① 标题公式（5分钟）

品牌词 + 产品词 + 核心卖点 + 场景
≤12字，核心词放前面。不要堆词。

示例：亚狮龙7号耐打训练球 家庭装

② 主图9图排列法（10分钟）

位置内容作用
1-3 视觉层封面/全景/侧背高清实拍建信任
4-6 细节层细节/瑕疵/配件消除信息差
7-9 信任层场景/凭证/尺寸促进下单

第一张图决定生死。 买家不点进去，后面全是废的。

③ 详情页五段式模板（5分钟）

① 标题段：一句话说清楚卖什么
② 人设段：我是谁+为什么卖（拉近距离）
③ 产品段：功能+状态（塑造专业感）
④ 规格段：配件清单（消除疑问）
⑤ 结尾段：价格+退换政策（引导下单）

④ 科学定价法（5分钟）

定价三步
查同款均价 → 评成色 → 留10-20%砍价空间
多用9/8尾数（39/48）
闲鱼用户心理：比淘宝便宜，但别太便宜

三、今天要发的品（5分钟）

🎯 今天发的3个品（讲师填写）
品A：____________ 标题：____________ 定价：____
品B：____________ 标题：____________ 定价：____
品C：____________ 标题：____________ 定价：____

以上品已备好素材包，直接复制发布即可

四、讲师完整演示（15分钟）

讲师投屏展示一个完整上架流程：

① 打开闲鱼 → ② 点"卖闲置" → ③ 选今天要发的品
④ 写标题（套公式） → ⑤ 排9张图 → ⑥ 填详情（套模板）
⑦ 定价 → ⑧ 发布

学员同步在自己的手机上操作。

五、发布后怎么看数据（10分钟）

指标合格线不合格→动作
曝光≥50优化标题/关键词
点击率(CTR)≥8%换第一张主图
"我想要"≥3个价格或需求问题
咨询≥1个优化详情页/话术
⏰ 设闹钟
11:30 第一次看数据
16:00 第二次看数据
数据记到台账：曝光 / CTR / 想要 / 成交，每天就记这4个数

六、散场确认（5分钟）

  • 账号已实名 + 芝麻信用已授权
  • 硬件隔离确认（独立手机 + 独立SIM卡 + 4G/5G）
  • 2-3个产品已发布
  • 知道11:30和16:00要看数据
  • 知道台账怎么记

Day 2 · 复盘优化

🔥 目标：逐人过数据，没出单的知道怎么调，出单的知道怎么放大

一、数据复盘（15分钟）

逐人过昨天数据
· 曝光多少？CTR多少？有人出单吗？
· 出单的人分享——为什么能出？做了什么不一样的事？
· 没出单的诊断——问题出在哪？
问题诊断动作
曝光低关键词/标题/权重优化标题核心词前置 + 养号
点击低主图/价格换第一张主图
咨询少详情页/话术改文案 + 优化快捷回复
零成交价格或信任不足降5%或考虑补1单

滞销品处理： 5-7天零曝光零咨询的商品直接删除，避免拖累店铺权重。

二、流量池晋级（15分钟）

曝光量分级速查

曝光量判断动作
<100❌ 放弃下架重发或换品
200-500⚠️ 观察优化主图/标题
≥500✅ 正常可用，继续推进
≥1000✅ 可用投5.9元测ROI

晋级三件套

① 擦亮：早7-9/午12-14/晚19-22（流量高峰前操作）
② 秒回：消息5分钟内回复，平台给快响账号更多流量
③ 补数据：数据达标的链接继续发布同款

投流入门：曝光>1000才投。5.9元测试，ROI>5继续投，不达标停。

数据诊断三步法

问题诊断动手
曝光低关键词/权重标题核心词前置 + 养号提升权重
点击低主图不行换第一张主图（最关键的）
转化低详情/话术改文案 + 优化快捷回复

三、客服话术与售后（15分钟）

话术模板

场景直接说
首次咨询"哈喽~这个上周买的就用了一次，不太适合我"
议价"真的最低了哥，再低要亏邮费了😭 送你个小配件行不？"
发货延迟"不好意思课多，晚上给你发，发的时候拍视频~"
求好评"亲如果觉得ok方便给个好评吗？谢谢你呀~"

核心： 个人卖家身份，别像客服机器人。

售后保护

发货闭环： 获取买家信息 → 去货源平台代拍 → 回传单号
防"到手刀"： 发货前拍完整视频（含SN码）→ 全流程录像打包 → 箱体加防拆标记
纠纷原则： 闲鱼内沟通留证，拒绝私下协商。
售后权重保护： 明确发货时效 → 友好协商为主 → 积极处理中差评

四、安全操作须知（10分钟）

补单安全规范

⚠️ 铁律
· 独立设备 + 独立网络（不满足这条就别补）
· 自然成交:补单 ≥ 7:3
· 同一个品一天不超过1单

操作流程： 小号搜关键词找到你 → 先看2-3个竞品（30秒+） → 回来看你的详情页（1分钟+） → 点"我想要"或收藏

日常必做清单

  • 每天擦亮（流量高峰前操作）
  • 消息5分钟内回复
  • 每天看数据 + 记台账
  • 每天至少上新1个

五、后续路径（5分钟）

🚀 后续方向
· 出单的品 → 加库存 + 升级主图 + 继续发同款
· 不出单的品 → 5-7天零数据 → 删掉重发
· 进阶自学 → 看下方「参考材料」
· 有问题 → 找____（讲师填写对接人）

参考①：复盘重点（12条核心检查项）

每天实操前花3分钟过一遍，哪个没做到优先补哪个。

关键点一句话自检
一机一卡一IP物理隔离，杜绝WiFi共享，禁分身/双开☐
芝麻信用≥650授权芝麻分，分数越高搜索排位越前☐
点击率≥8%首日CTR不过8%直接换主图☐
响应≤5分钟超时成交率骤降，平台给快响账号更多流量☐
严禁站外导流不引流微信/QQ/淘宝☐
严禁违禁词不用"全新""100%正品""全网最低"☐
补单≤30%独立设备+独立网络☐
7天内避免大幅改价大幅调价打乱标签导致降权☐
人设"若即若离"个人卖家人设天然降低买家防御心☐
每日擦亮早7-9/午12-14/晚19-22流量高峰前操作☐
滞销品5-7天清理零曝光零咨询直接删除☐
每日数据全记录台账记录曝光/CTR/成交☐

  • 账号人设已搞定（头像/简介/动态）

每日必做

  • 早上10点前上品
  • 11:30看数据（曝光/CTR/想要）

  • 擦亮操作
  • 消息秒回

参考③：20字黄金成交公式

精细选品 → 优质内容 → 合理价格 → 高效运营 → 口碑沉淀
环节本质关键动作
精细选品选对赛道近7天出单？利润≥30%？货源验证？
优质内容决定点击率标题12字+9图排列+详情五段
合理价格引流不亏本低于竞品10-15%，留砍价空间
高效运营维持权重秒回+擦亮+补单+话术库+数据记录
口碑沉淀长期复利人设拦截差评+主动要好评+售后保护

参考④：硬件与账号详解

一机一卡一IP

要求说明
一机一卡一IP物理隔离独立手机+专属SIM卡+4G/5G移动数据
严禁分身禁止应用分身、双开、虚拟机
SIM卡优选不同运营商及归属地
实名认证真实身份，完成人脸核验
资金隔离每个闲鱼号绑定独立实名的支付宝

账号包装三要素

要素要求
头像/昵称高清真人照或品类相关图；昵称含核心词（如"数码玩家小李"）
简介三段式①我是谁 ②卖什么 ③给承诺
动态发2-3条日常动态增强真实感

刷对标操作

搜品类关键词 → 每天点10-15个"我想要" → 收藏5-8个 → 浏览详情页30秒+ → 咨询2-3个竞品收集话术 → 每号每天刷30分钟+

参考⑤：选品逻辑

选品三条件

条件核心问题
有出单记录同类品近7天有人出单吗？
利润≥30%毛利率基准30%，验证1688/拼多多货源
有差异空间你能做和别人不一样的点吗？

数据化选品流程： 搜核心词 → 看下拉推荐词（需求分析）→ 看"相似商品"及"已卖出"记录（供给分析）→ 测利润

参考⑥：售后保护详细操作

无货源发货闭环

① 获取买家信息 → ② 去货源平台代拍 → ③ 备注：严禁放价格单/店铺卡片 → ④ 复制快递单号 → ⑤ 回传闲鱼点击发货 → ⑥ 退货时指导买家退回给供应商

防"到手刀"检查清单

  • 发货前录制完整展示视频（含SN码/序列号）
  • 全流程录像打包
  • 箱体加防拆标记
  • 遇纠纷：拒绝私下协商（须在闲鱼沟通留证）
  • 坚决拒绝不合理要求
  • 申请小法庭/客服介入

售后权重保护

明确发货时效（如拍下48小时内发货）→ 尽量远离小法庭（友好协商为主）→ 平台介入无论对错均损害权重 → 积极处理中差评 → 真诚沟通引导修改
