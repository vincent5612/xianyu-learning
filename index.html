📤 每日发布草稿 需演示

🔥 每天 2 个草稿。讲师投屏自己的手机，在屏幕上演示一遍完整操作。
学员跟着做，做完检查。
📱 讲师操作流程（投屏演示）：
1. 切出投屏 → 打开自己手机闲鱼APP
2. 完整做一个草稿：拍照/选图/写文案/定价/标标签
3. 让学员跟着操作 → 做完逐个检查
4. "你们做完没有？做完了过来检查"

草稿要素

要素要求
标题品牌词+产品词+核心卖点+场景+人群词，12字左右，AI生成
主图高清 + 个人手写纸条水印（防盗图 + 真实感）
文案个卖口吻（"买多了用不上"），抄同行→AI改
定价低于竞品 10-15%，不做绝对低价（触风控）
标签选相关品类标签
⚠️ 同品不同账号必须换主图（不同角度/背景）+ 微调定价（110/115/105 三档）+ 改文案关键词 — 避免判定重复铺货。

📊 第二次数据检查（20:00 晚上）+ 补单决策

🔥 判断流量池状态：
曝光 CTR ≥ 8% → 第二天必涨曝光，只是几千或一两万而已
曝光 < 100 → 直接放弃，不等了
检查项合格线不合格 → 动作
曝光增长持续增长停滞 → 考虑补单
点击率≥ 8%未达标 → 明天优化
收藏 / 咨询收藏 ≥ 5，咨询 ≥ 1图片不够吸引/被动

流量池判定标准

曝光量判定动作
< 100❌ 直接放弃下架重发或换品
200-500⚠️ 观察优化主图/标题
≥ 500✅ 正常内容可用，继续观察
≥ 1000✅ 可用投 5.9 元测 ROI，预期 3 倍+
⚡ 补单决策：曝光够但没成交 → 补单。一个链接 ≥ 2 单，配合曝光量级调整。补不动 → 先投点流量再补。

🛡️ 安全补单操作

⚠️ 铁律：补单小号必须独立设备 + 独立网络。同WiFi下补单 = 自杀。自然成交:补单 ≥ 7:3。
📸 [配图：补单图文步骤]
已有补单文档嵌入此处——编号 1-2-3-4 引导式
  1. 小号搜关键词找到自己商品
  2. 浏览 2-3 个竞品页面（30 秒+）
  3. 回到自己商品浏览详情（1 分钟+）
  4. 点击"我想要"或收藏
  5. 如需补成交：咨询 → 议价 → 下单 → 正常走完流程
  6. 同一个品一天不超过 1 单
📊 补单量参考：
曝光小 → 先投点流量 → 再补一单提权重。
正常链接每号每天 ≥ 2 单（自然+补单合计）。

⚡ 优化未达标链接

🔥 核心判断标准：72 小时测试期，但 8~9 成在 24 小时就能体现。
曝光 < 100 → 直接斩掉，不要等第三天爆。

优化三步走

  1. 卡关键词 → 搜你的关键词，看自己在不在前列。不在 → 换标题
  2. 卡地域 → 看同地域竞品，是不是比你好。好 → 学他的主图/定价
  3. 卡价格 → 同行突然降价？有人在黑你。考虑微调或换品
🚨 卡关键词找不到 + 卡地域找不到 → 大概率废了。
排除老师教的问题后，就是大量竞品在围剿你。价格降 5 毛别人都可能掉下来——你需要差异化突围。
问题动作
曝光低（<100）下架重发 or 换品
有曝光无点击换主图（第一张最关键）
有点击无咨询改文案 + 降价试探
有咨询无成交话术问题 → 抄竞品话术

💰 想要（闪亮） — 固定收入

💵 核心：想要 = 2 毛/个，零成本纯利润。学员配合做成果账号，15 天冲到全国前 10。
各带班老师统计谁拿了多少想要 → 算钱。

为什么重要

  • 我们卖想要给学员 → 我们的成本 = 0 → 纯捡钱
  • 学员用想要做成果账号 → 数据好看 → 学员满意度高
  • 我们要保证：15 天/月内做到全国前 10

操作方式

  1. 学员每天固定拿想要的量（讲师分配）
  2. 配合闪亮一起使用，打造账号权重
  3. 讲师统计谁哪班拿了多少，月底算账
角色动作
培训老师讲课中着重讲"想要"的重要性（2 分钟）
带班运营统计各学员想要使用量
学员配合在账号上使用想要/闪亮
💰 收入模型：卖 20 个想要 = 成本 0 元，纯利润。卖越多赚越多。固定收入来源。
比卖课还稳——学员越用想要，数据越好，越相信你。

📄 SOP 流程 + 下周计划

⑤ 建立 SOP

  • 把 5 天每日动作写成标准流程，以后照做
  • 每个环节标清：做什么 → 怎么做 → 检查什么

⑥ 下周计划

  • 矩阵扩张方向？要不要试投流？（先投 20-50 元测成本）
  • 内容端：小红书 / 抖音种草引流到闲鱼
  • 上新计划：每个号再加 1-2 个链接
  • 想要/闪亮收入目标定下来
✅ 死线：复盘完成 + 产品决策 + SOP初版 + 下周计划 + 想要收入目标

✅ 5 天执行检查清单

每天做完一项就点一下 ☐

Day 1 · 准备日

  • ☐ 读完规则红线（5条，拍照留存）
  • ☐ 硬件隔离确认（3账号各自独立设备+网络）
  • ☐ 3个人设已确定（≥3种，截图标注）
  • ☐ 刷对标养号完成（每号30分钟+）
  • ☐ 品类研究到位（选品逻辑 + 供应链分析）
  • ☐ 每号至少2个商品草稿已准备完毕

Day 2 · 发布日

  • ☐ 早上07:30-09:00发布商品（每号至少2个）
  • ☐ 中午12:00第一次数据检查（曝光/CTR/我想要）
  • ☐ 晚上20:00第二次数据检查+记录台账
  • ☐ 根据数据决定是否补单
  • ☐ 完成今日运营基础动作
  • ☐ 记录所有数据到台账

Day 3 · 优化日

  • ☐ 判断流量池状态（按曝光标准决定去留）
  • ☐ 擦亮所有在售商品
  • ☐ 对未达标链接做优化（卡关键词/卡地域/卡价格）
  • ☐ 执行补单（安全操作规范）
  • ☐ 检查并优化快捷回复话术
  • ☐ 至少完成1单（自然成交或安全补单）

Day 4 · 进阶日

  • ☐ 话术库建好（抄头部→改本地化→AI优化）
  • ☐ 前3天数据复盘
  • ☐ 对表现不佳的链接做调整
  • ☐ 理解账号权重（显性/隐性，个人/专业）
  • ☐ 熟悉想要/闪亮收入模式
  • ☐ 继续上新链接（每号再加1-2个）

Day 5 · 复盘日

  • ☐ 完成所有数据复盘（产品/运营/账号/利润四维度）
  • ☐ 产品迭代决策（淘汰/优化/加码/上新）
  • ☐ 建立初步SOP标准操作流程
  • ☐ 制定下周计划（矩阵扩张/投流测试/想要目标）
  • ☐ 完成考试（Day1 + Day5）
