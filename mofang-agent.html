01

代理商模式

本合作仅设置集采模式，且仅适用于线下销售。合作须签署正式代理协议，单次拿货量不少于 100 台。

A集采模式

乙方与甲方签订框架集采协议，按对应等级代理基准价向甲方采购硬件 + 激活码。

乙方自建库存、自主收款销售，硬件销售差价归乙方所有。

设备激活时绑定乙方归属台账，乙方享有对应等级的 Token 管道分润。

B集采提货规则

  • 框架协议约定总集采台量
  • 剩余份额可分批次下单提货
  • 每一批次下单拿货数量不得少于 100 台

C销售限价与渠道范围

所有规格产品对外销售，售价不得低于零售指导价。

本合作模式仅适用于线下销售，不参与电商、直播等线上渠道销售。

04

Token 管道收益　长期被动收益

区别于一次性硬件销售差价，管道收益来自乙方名下已售出、已激活设备后续产生的 Token 实际消耗流水，按代理等级比例持续计提。用户充值但未消耗的 Token 金额不计入分润基数。

1归属绑定规则

  • 设备首次激活成交时绑定归属代理商
  • 设备后续转售、转让，管道收益归属不变，不随设备流转变更
  • 一台设备仅归属单一代理商，不重复分润

2收益终止条件

  • 设备硬件报废、永久停用、激活失效
  • 不再产生 Token 消耗，即停止该台设备管道分润
  • 后台设有独立归属台账，归属隔离、统一口径

3等级联动与独立核算

  • 代理商升级后，名下全部存量设备自动切换为新等级分润比例
  • 硬件差价收益、Token 管道收益为两笔独立收益
  • 分开对账、分开结算，互不冲抵

对账与结算规则

STEP 01

按月结算

结算周期为按月结算，甲方每月出具 Token 消耗明细对账报表。

STEP 02

3 个工作日核对

乙方收到对账报表后 3 个工作日内核对确认，逾期无书面异议视为认可账单。

STEP 03

对公结算开票

对公转账结算，乙方开具合规发票，税务合规走公司对公流程。

STEP 04

分开对账结算

硬件货款与 Token 管道分润分开对账、分开结算，两笔收益互不混同。

物料支持

技术支持

培训支持

售后支持

对账结算

代理商硬性规则

以下四条为合作红线，签约后纳入代理协议约束条款。

1

限价规则

严禁低于最低指导价倾销、乱价。甲方有权核查渠道售价，乱价按协议处罚，严重者可暂停分润、取消代理资格。

2

窜货管控

集采批次设备绑定代理商台账，窜货行为按合作协议处理。

3

渠道范围

本合作模式仅适用于线下销售，不参与电商、直播等线上渠道销售；代理商不得以任何形式在线上渠道上架、分销本产品。

4

经营范围要求

代理商公司营业执照经营范围须包含计算机软硬件销售、人工智能硬件销售、信息技术咨询等相关类目（以甲方提供的经营范围清单为准）。
